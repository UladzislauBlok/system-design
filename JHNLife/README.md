### What is System Design?

System Design is the strategic decision-making process for creating a large-scale software system that is both reliable and performant under heavy load.

It moves beyond storing data on a single machine by focusing on distributing the system across multiple components and servers.

The core goal is to optimize the entire lifecycle of data:

| Aspect                             | Focus                                                                                                                      | Goal                                                                      |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Storage & Retrieval (Reads/Writes) | Selecting the right hardware (RAM, HDD, SSD) and location (Application Server, Database Server) for data.                  | Making data access faster and ensuring it is always available (reliable). |
| Data Processing                    | Defining the computations and transformations that happen on data (e.g., validation, batch processing, stream processing). | Ensuring data is transformed correctly and efficiently for consumption.   |

#### Data-Intensive Applications

System design is essential for Data-Intensive Applications, where the primary challenge is managing the quantity, complexity, and speed of data. Such systems must be designed around the three core pillars:

- Reliability: Functioning correctly despite faults.
- Scalability: Handling growing demand and data volume.
- Maintainability: Being easy to operate and modify.
